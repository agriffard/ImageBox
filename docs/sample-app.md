# Sample App

Run the sample locally:

```bash
dotnet run --project /tmp/workspace/agriffard/ImageBox/ImageBox.Sample/ImageBox.Sample.csproj
```

The app demonstrates:

- Responsive masonry gallery layout
- Lightbox modal with previous/next navigation
- Keyboard controls (`←`, `→`, `Esc`, `+`, `-`)
- Zoom controls in the lightbox toolbar
